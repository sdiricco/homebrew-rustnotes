# Homebrew tap for RustNotes

```bash
brew install --cask sdiricco/rustnotes/rustnotes
```

Upgrade with `brew upgrade --cask rustnotes`. The app is not code-signed: on
first launch right-click → Open, or run
`xattr -dr com.apple.quarantine "/Applications/RustNotes.app"`.

RustNotes: https://github.com/sdiricco/rustnotes
